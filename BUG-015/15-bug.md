# Bug Report

## Bug ID
BUG-015

## Title
Incorrect spacing before the last letter in "Return to Store" button text

## Environment
- OS: Windows / macOS
- Browser: Chrome / Firefox / Edge
- Website: https://academybugs.com

## Preconditions
User is on the AcademyBugs homepage.

## Steps to Reproduce
1. Open the browser and navigate to `https://academybugs.com`
2. Click on the **Find Bugs** link in the navigation bar
3. Click on any product to open its details page
4. Scroll down to the cart section in the right side menu
5. Clear all items from the cart if any are present to trigger the empty cart state

## Expected Result
The text caption on the "Return to Store" button should have even, consistent spacing between all letters.

## Actual Result
There is excessive space before the final letter in the "Return to Store" button caption.

## Severity
Low

## Priority
Low
