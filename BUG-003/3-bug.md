# Bug Report

## Bug ID
BUG-003

## Title
Manufacturer link under product quantity returns an error page

## Environment
- OS: Windows / macOS
- Browser: Chrome / Firefox / Edge
- Website: https://academybugs.com

## Preconditions
User is on the AcademyBugs homepage.

## Steps to Reproduce
1. Open the browser and navigate to `https://academybugs.com`
2. Click on the **Find Bugs** link in the navigation bar
3. Click on any product to open its details page
4. Click on the manufacturer link located under the quantity selector

## Expected Result
The manufacturer link should redirect the user to the correct manufacturer details page.

## Actual Result
The manufacturer link opens an error page instead of the expected page.

## Severity
Medium

## Priority
Medium
