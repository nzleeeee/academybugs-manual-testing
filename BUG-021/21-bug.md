# Bug Report

## Bug ID
BUG-021

## Title
Application freezes completely when attempting to change currency

## Environment
- OS: Windows / macOS
- Browser: Chrome / Firefox / Edge
- Website: https://academybugs.com

## Preconditions
User is on the AcademyBugs homepage.

## Steps to Reproduce
1. Open the browser and navigate to `https://academybugs.com`
2. Click on the **Find Bugs** link in the navigation bar
3. Click on any product to open its details page
4. Locate the currency selector in the right side menu and attempt to change the currency

## Expected Result
The currency should update successfully without affecting application performance.

## Actual Result
The page freezes completely and becomes unresponsive upon selecting a new currency.

## Severity
High

## Priority
High
