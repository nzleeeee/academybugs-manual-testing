# Bug Report

## Bug ID
BUG-013

## Title
Product short description and full description are displayed in non-English placeholder text

## Environment
- OS: Windows / macOS
- Browser: Chrome / Firefox / Edge
- Website: https://academybugs.com

## Preconditions
User is on the AcademyBugs homepage.

## Steps to Reproduce
1. Open the browser and navigate to `https://academybugs.com`
2. Click on the **Find Bugs** link in the navigation bar
3. Click on any product to open its details page

## Expected Result
The short description and full product description should be displayed in English.

## Actual Result
The short description and full product description are written in non-English placeholder text (e.g., Latin/Lorem Ipsum).

## Severity
Medium

## Priority
Medium
