# Bug Report

## Bug ID
BUG-005

## Title
X share button on product details page redirects to an error page

## Environment
- OS: Windows / macOS
- Browser: Chrome / Firefox / Edge
- Website: https://academybugs.com

## Preconditions
User is on the AcademyBugs homepage.

## Steps to Reproduce
1. Open the browser and navigate to `https://academybugs.com`
2. Click on the **Find Bugs** link in the navigation bar
3. Click on any product to open its details page
4. Click on the X share button

## Expected Result
The X share button should open the official share dialog or page to post the product link.

## Actual Result
The X share button redirects the user to an error page instead of the expected share page.

## Severity
Medium

## Priority
Medium
