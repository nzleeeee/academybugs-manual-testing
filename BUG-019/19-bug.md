# Bug Report

## Bug ID
BUG-019

## Title
Product from "Hot Item" sidebar section hangs on an infinite loading loop

## Environment
- OS: Windows / macOS
- Browser: Chrome / Firefox / Edge
- Website: https://academybugs.com

## Preconditions
User is on the AcademyBugs homepage.

## Steps to Reproduce
1. Open the browser and navigate to `https://academybugs.com`
2. Click on the **Find Bugs** link in the navigation bar
3. Click on any product to open its details page
4. Click on the product listed under the **Hot Item** section in the right side menu

## Expected Result
The product page for the selected Hot Item should load and render properly.

## Actual Result
The page hangs indefinitely in a continuous loading state without displaying the product.

## Severity
High

## Priority
High
